# ConsoleCalculator

Консольный калькулятор на Java. Домашнее задание по дисциплине «Программирование на Java», МИФИ.

## Возможности

- Базовые операции: `+`, `-`, `*`, `/`
- Накопление результата (результат становится первым операндом)
- Сброс (`C`)
- Выход (`S`)
- Ввод чисел с точкой или запятой
- Проверка деления на ноль
- Обработка некорректного ввода

## Стек

- Java 17
- Maven

## Запуск

1. Склонируй репозиторий.
2. Открой в IntelliJ IDEA.
3. Запусти `Main.java`.
